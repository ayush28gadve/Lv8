# ConceptTwin

> *"Prove you understand, don't just get it right."*

ConceptTwin is an AI-powered learning system tailored for Class 11–12 Physics students. Its core purpose is to evaluate whether a student genuinely grasps fundamental physics concepts rather than simply relying on rote problem pattern recognition.

---

## 📌 Project Status

**Current Status**: Phase 0 — Project Setup  
*Note: AI, agent orchestration, evaluation engines, and database functionalities will be introduced in subsequent development phases.*

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have Node.js (v18+ recommended) and npm installed.

### 2. Environment Variables
Copy the example environment configuration:
```bash
cp .env.example .env.local
```

### 3. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### 4. Build for Production
```bash
npm run build
npm run start
```
